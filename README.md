🔍 Project Overview

This Power BI dashboard is designed to analyze, visualize, and interpret data effectively using interactive charts, tables, and filters.
The main goal of this dashboard is to convert raw data into meaningful insights that help in better decision-making.

This project demonstrates my understanding of:

Data modeling

Data visualization

Business insights generation

Power BI tools and features

🛠 Tools & Technologies Used

Power BI Desktop

Power Query – Data cleaning & transformation

DAX (Data Analysis Expressions) – Calculated measures & columns

Excel / CSV Dataset (as data source)

📂 Data Preparation (ETL Process)
1️⃣ Extract

Imported raw data from Excel/CSV files into Power BI.

2️⃣ Transform

Using Power Query Editor, the following operations were performed:

Removed duplicate values

Handled missing/null values

Renamed columns for better understanding

Changed data types (Date, Number, Text)

Created custom columns where required

3️⃣ Load

Cleaned and transformed data was loaded into the Power BI data model.

🧠 Data Modeling

Relationships were created between multiple tables using Primary and Foreign Keys

Star schema was followed for better performance

Fact and Dimension tables were properly structured

📐 Measures & Calculations (DAX)

Some important DAX concepts used:

SUM, COUNT, AVERAGE

CALCULATE

FILTER

Date-based calculations

Percentage & ratio calculations

These measures help in generating accurate KPIs and insights.

📈 Dashboard Visuals Explained
🔹 KPI Cards

Display key performance indicators such as:

Total Sales / Revenue

Total Orders

Average Value

Growth Percentage

👉 Helps users quickly understand overall performance.

🔹 Bar & Column Charts

Used to compare values across:

Categories

Regions

Products

Makes trend and comparison analysis easy.

🔹 Line Chart

Shows time-based trends

Helps in understanding growth, decline, or seasonality.

🔹 Table & Matrix Visuals

Displays detailed data in tabular format

Matrix is used for hierarchical analysis (Year → Month → Day).

🔹 Slicers (Filters)

Interactive slicers are provided for:

Date

Category

Region

Product

👉 Enables users to analyze data dynamically based on their selection.

🎯 Key Insights from Dashboard

Identifies top-performing categories and regions

Helps track trends over time

Highlights areas with low performance

Supports data-driven decision making

🔐 Dashboard Access & Sharing

Due to Power BI admin restrictions, Publish to Web may be disabled.
This dashboard can be shared using:

Power BI Service (Share option)

Screenshots / PDF export

PBIX file (for review)
